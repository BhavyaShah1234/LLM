# Pinned dependency list for the LLM/mLLM training & optimization research project.
#
# Versions below were confirmed installed and working (in a separate Python 3.12 env)
# on 2026-08-15, on a single 8GB-VRAM NVIDIA RTX 5060 Laptop GPU, and separately
# verified against PyPI to ship compatible wheels for this project's Python 3.14
# venv (llm/) -- see pretraining/README.md and the root README's environment
# section for details. `deepspeed` and `flash-attn` have no prebuilt wheels for
# *any* Python version (source-only, `.tar.gz`) so expect them to compile on
# install regardless of interpreter version -- this is normal, not a 3.14 issue.
#
# `datasets` is bumped from the originally-confirmed 2.17.1 to 5.0.1 for two
# real reasons found while installing into llm/: (1) 2.17.1 pulls in dill<0.3.9,
# whose old pickle internals are incompatible with Python 3.14's stdlib pickle
# module (TypeError in Pickler._batch_setitems); 5.0.1 allows dill<0.4.2, which
# fixes it. (2) trl==1.9.2 itself requires datasets>=4.7.0, so 2.17.1 was never
# actually installable alongside trl regardless of Python version. The
# load_dataset/.map/.select/.shuffle/.take API this project uses is stable
# across this range, so the bump carries no known script-compatibility risk.
#
# `trl`, `vllm`, `deepspeed`, `torch-geometric` are present for future waves
# (RLHF, production serving, distributed optimization, graph modality) and are
# not required by Wave 1's pretraining/ scripts themselves.
